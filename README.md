# README — Telegram RAG-бот (aiogram + Milvus Lite + Jina v3 + GigaChat)

Проект: RAG, которая принимает документы в Telegram, индексирует их в Milvus Lite, извлекает релевантные фрагменты по запросу и формирует ответ либо списком фрагментов, либо через GigaChat.

## Возможности

- Приём документов в Telegram и сохранение в `./uploads/`
- Индексация: парсинг, чанкинг, эмбеддинги Jina v3 (Transformers), запись в Milvus Lite (`./data/milvus.db`)
- Поиск релевантных фрагментов по запросу
- Режимы ответа:
  - Списком фрагментов (без LLM)
  - Связный ответ через GigaChat (конфигурируется)
- Команды `/start`, `/help`

## Технологический стек

- Python 3.11+
- aiogram v3
- Milvus Lite (через `pymilvus.MilvusClient` с локальным файлом БД)
- Transformers + `jinaai/jina-embeddings-v3` (локальная инференс-модель, CPU/MPS)
- GigaChat (`gigachat`, `langchain-gigachat`) для генерации итогового ответа
- python-dotenv для подхвата `.env`

## Быстрый старт

### 1) Подготовка окружения

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 2) Настройка переменных окружения

Создайте `.env` в корне проекта.

Обязательно заполните `BOT_TOKEN`. Для включения GigaChat заполните `GIGACHAT_CREDENTIALS`. Если оставить его пустым или выставить `RAG_USE_LLM=false`, бот будет отвечать списком фрагментов без LLM.

### 3) Запуск

Из корня проекта:

```bash
python -m bot.app
```

Бот автоматически загрузит `.env`. В Telegram откройте бота и используйте `/start`.

## Использование

- Команда `/start` показывает инструкцию и кнопки.
- Кнопка «Загрузить документ» подсказывает, как отправить файл как документ.
- После загрузки начнётся индексация; по завершении задавайте вопросы в чате.
- Если включён режим LLM, итоговый ответ формируется GigaChat на основе найденного контекста; иначе возвращается список лучших фрагментов с указанием документа.
